# How to choose an event type

Use when the user asks which event to do, how to split an event budget, or what goes into the event calendar. Every figure is the user's or a field. Patterns from the method are offered as hypotheses to test against the user's own data, never as facts about their market.

## 1. The comparison table for a single bet
Options sit in columns, rated on these rows. Fill each cell from the organiser's proposal, the user's data or a cited page; anything else is "[User to add: ...]".

| Row | Option A | Option B | Option C |
|---|---|---|---|
| Format (for example breakfast roundtable, stall at a trade show, sponsored summit, webinar series) | | | |
| What do we get? (speaker slot, stall, guaranteed one to one meetings with senior buyers, breakout sessions) | | | |
| Organiser | | | |
| Credibility in the market (how buyers and peers see the organiser and the event) | | | |
| Benefit for the launch or for relationships (for example inviting top clients as references) | | | |
| List match with the ideal customer profile (share of invitees who are ideal customers, compared with an event where every guest comes from your own chosen list) | | | |
| Package cost, with quotes from other vendors as footnotes | | | |

Ask the organiser to commit in writing to anything in "What do we get?" and to the list match. Never fill the list match or the cost from memory.

## 2. Funnel economics per type
For each type, the fields of shared-process.md section 2: relevant target share, old against new account mix, conversion to the first qualified stage, conversion to the stage sales accepts, and cost per accepted lead. Run `scripts/plan_math.py` on the user's figures.
Pattern from the method (a hypothesis): small custom regional formats tend to win on conversion; large format events tend to win on reach into new accounts.

## 3. Type by funnel stage and audience
- Discovery: webinars and industry events.
- Early opportunities with senior buyers: a breakfast or a workshop.
- The advisers one level below the decision maker, and stalled deals: events and webinars.
- Influencers: PR and analysts (see analyst-and-programmes.md).

## 4. Type by company stage
In the method, event led and outbound growth belong to a company that already has repeatable revenue (the method places it at the Series A stage). Earlier stages rely on founder led sales, demos and product led growth. Ask the user's stage and revenue in their own words; the boundary is [User to add].

## 5. Type by plan phase and account tier
- A phased plan: foundation first (positioning, lists, content), then an authority phase with webinars, then a demand phase with sponsorships and exhibitions. The length of each phase is [User to add].
- In account based marketing: top tier accounts (one to one) get senior buyer roundtable invitations as engagement hooks; the second tier gets webinar invitations; the third tier gets programmatic nurture. The tier definitions are the user's.

## 6. Type by budget
- With no paid media budget: a series of webinars, LinkedIn Lives or podcasts with similar partners and speakers, aimed at people who reacted to past sessions.
- "No budget" for an in person event (for example a roundtable): ask whether it means the budget is not known yet or that it is zero. Not known: plan with the cost as a field. Zero: say that the venue and hospitality cost is still real; offer a format co-hosted with a partner who pays a share agreed in writing (hosted-formats.md section C) or an online format from the line above, and never assume a venue will be free.
- Content and search work take time to produce qualified leads; do not plan them as the event budget's replacement for the current quarter.
- Budget lines: one line per event type and per exhibition, plus tools (for example the video conferencing tool for webinars). All amounts are [User to add].

## 7. Seasonality
Decide which quarters carry in person events and which carry webinars, from the buyers' own calendar (budget cycle, holidays, trade show season, quarter close) [User to add]. A common choice in the method is to make the middle quarters of the year heavier on in person events and to run more webinars in the last quarter so those leads can be nurtured; you decide. If every region has the same target, plan for every region rather than the easiest one.

## 8. The learned allocation (a hypothesis)
In the method's experience, small face to face formats plus online formats worked for enterprise accounts, and exhibitions suited the small and mid sized segment. Check this against the user's own win data before using it; say so in the plan.

## 9. Output of a choice
1. The comparison table with every cell sourced or a field.
2. The funnel economics per option (script output or fields).
3. The fit with funnel stage, company stage, plan phase, budget and season, one line each.
4. What would decide it: the one or two inputs still missing.
5. A recommendation only when the user's figures support it, worded as "on your figures, option B delivers ..."; otherwise "not enough data to choose; here is what decides it".

## 10. Common mistakes
- Choosing a show because competitors are there, without checking the list match and the cost per accepted lead.
- Comparing options on package cost alone.
- Treating a pattern from someone else's market as a benchmark for this one.
- Planning only the easy region when every region carries the same target.
