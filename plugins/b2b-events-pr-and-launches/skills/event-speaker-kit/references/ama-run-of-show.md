# AMA run of show (ask me anything sessions)

Use when a session is built around a published piece (an article, a report, a guide) and the audience asks questions live.

## 1. The spine
The published piece is the spine. Read it in full first. If the skill cannot open it, say so and ask the user to paste it; never reconstruct it from memory.

## 2. Mapping note
A table from the piece's sections to the AMA areas the user chose:
| Section of the piece | AMA area | Panelist or host who takes it | Audience action at the end of the block |
|---|---|---|---|
Every block ends with one audience action (a question to type in the chat, a one word answer, a poll). Use a one word audience prompt at the start to get the chat moving.

## 3. Parking list
Areas of the piece that this session will not cover, each with one line: "Kept for a later session". Say this out loud when an audience question lands in a parked area.

## 4. Scope control lines
Four short lines the moderator can say to bring a session back on scope, written in the moderator's voice, for example:
- when a question is about a parked area;
- when a question asks for a product recommendation or a vendor comparison;
- when a question needs private client details;
- when one person takes too long.

## 5. Ten backup questions
Ten questions the moderator asks if the audience is quiet, each tied to a section of the piece and to the audience's role. Mark which ones are safe to drop.

## 6. Closing line held in reserve
One closing line the moderator keeps ready if time runs out early or late. It points to where the audience can continue (the piece, a follow-up session), with no pitch.

## 7. Links and calls to action
No "comment a keyword to get the link" mechanic. Registration and article links go where the platform allows them (the event page, a pinned comment), never as a reward for engagement.

## 8. Logistics block
Platform, link owner, who admits speakers, who watches the chat, recording and consent, time zones of the audience (write every time with its zone).

## 9. When the user is in a rush
Give the ten backup questions, the four scope lines and the closing line first; the mapping table after.
